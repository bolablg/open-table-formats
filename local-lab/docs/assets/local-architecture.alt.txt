One unchanged local source file, olist_orders_dataset.csv, is mounted read-only into Docker. JupyterLab and Apache Spark 3.5.7 read its eight business columns and write new Parquet files plus table metadata into three separate prefixes in LocalStack S3-compatible object storage. Iceberg uses iceberg/lab/orders with data and JSON/Avro metadata. Delta uses delta/orders with Parquet and a _delta_log transaction log. Hudi Copy-on-Write uses hudi/orders with Parquet, a completed .hoodie timeline and auxiliary metadata table. The CSV is outside the S3 table prefixes and is not converted in place. Spark captures operation evidence into saved JSON. The local browser explorer reads that saved evidence, not live tables. CSV and Parquet are file formats; Iceberg, Delta and Hudi are table formats. Solid arrows mark table writes; dashed arrows mark reads or saved evidence capture, with direction and labels distinguishing them.
